WhatsApp Web in its own window

Not another tab that disappears into the pile. One window with its own taskbar entry, the unread count on the toolbar, and a keyboard shortcut. That is the whole product.

Download Source

What it does

  • Dedicated window — opens web.whatsapp.com as a popup window, no tab strip, no address bar.
  • One window, not five — clicking the icon again brings the existing window to the front.
  • Unread badge — the (3) in the tab title becomes a badge on the toolbar icon.
  • Keyboard shortcut — Ctrl+Shift+Y (⌘⇧Y on macOS), rebindable.
  • Options that stick — window or tab, and the exact window size.

What it refuses to do

  • No content script. Nothing is injected into the page. The badge comes from the tab title, a first-class browser API.
  • No network requests. The background script has zero fetch. Your messages never touch anything but WhatsApp's own servers.
  • No remote code. No eval, no Function, no CDN script — the build fails if any appear.
  • No data collected. Two permissions: windows and storage. No account, no analytics, no identifiers.

Install right now, without a store

  • Chrome, Edge, Brave, Opera: download the zip, unzip it, open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.
  • Firefox: download the .xpi, open about:debugging#/runtime/this-firefox, Load Temporary Add-on, pick the file.

Store listings are being set up. Until then the manual install above is the supported path, and it is the same code.
