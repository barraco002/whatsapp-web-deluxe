Privacy policy

WhatsApp Web Deluxe — last updated 24 October 2026

The short version

This extension collects nothing. No analytics, no telemetry, no crash reports, no usage statistics, no advertising identifiers, no accounts. There is no server to send anything to.

What is stored, and where

  • A window id in chrome.storage.session: memory only, cleared when the browser session ends. It exists so a second click focuses the window instead of opening another one.
  • Your three preferences in chrome.storage.sync: window or tab, width and height. If you have browser sync enabled, your browser vendor may sync them across your own devices; that is your browser's behaviour, not a server of ours.

Nothing else is written to disk. There is no database, no log file and no exported history.

What the extension can see

  • Tab titles of https://web.whatsapp.com/, read through chrome.tabs.onUpdated to turn (3) WhatsApp into a badge that says 3.
  • That is the entire surface. There is no content script, so page content, message text, contacts and media are never read, never parsed and never copied anywhere.

Network

The background script makes no network requests. It has no fetch, no XMLHttpRequest and no remote script. Everything you type goes from your browser to WhatsApp's own servers exactly as it would in a normal tab.

Permissions, and why each one exists

  • windows — create, focus and measure the dedicated window.
  • storage — remember the window id and your three preferences.
  • host_permissions: https://web.whatsapp.com/* — needed to observe that tab's title for the badge.

No tabs, no notifications, no <all_urls>, no webRequest, no cookies.

Third parties

None. No third-party service, SDK, library or CDN is used. The extension is one manifest, one background script, one options page and four PNG icons.
